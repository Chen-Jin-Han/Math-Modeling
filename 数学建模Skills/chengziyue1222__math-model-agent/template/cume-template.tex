\subsection*{附录B\quad 自有完整源程序（src/main.py）}

以下代码作为“完整文件”的排版示例。实际论文必须用同样方式纳入全部自有源程序，不得只摘录关键代码。

\begin{pycode}
import argparse
import json
from pathlib import Path

import pandas as pd
from sklearn.linear_model import Ridge

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--data", default="data/data.csv")
    parser.add_argument("--output", default="results.json")
    args = parser.parse_args()

    frame = pd.read_csv(Path(args.data))
    X = frame.drop(columns=["target"])
    y = frame["target"]
    model = Ridge(alpha=1.0).fit(X, y)
    result = {"intercept": float(model.intercept_),
              "coefficients": model.coef_.tolist()}
    Path(args.output).write_text(
        json.dumps(result, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )

if __name__ == "__main__":
    main()
\end{pycode}
