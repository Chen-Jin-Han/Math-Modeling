# 智感Nova比赛现场演示脚本

## 开场（15 秒）

“智感Nova不替代校园负荷预测模型，也不只看预测精度。它在模型进入未来 24 小时高风险辅助研判前，检查模型是否具备可追溯的可信证据。”

## 案例一：时间泄漏（45 秒）

1. 选择 `CASE-DEMO-002｜首演案例｜BLOCKED`，点击“开始可信诊断”。
2. 指出 Risk 中的未来时点特征风险。
3. 指出 Nova Core 选择并执行 `LEAKAGE_CHALLENGE`。
4. 沿 Evidence 链说明：实验结果形成反证，最终 Gate 为 `BLOCKED`。
5. 强调：高风险辅助研判被阻断，不是简单给出模型好坏评价。

## 案例二：证据闭合（35 秒）

1. 选择 `CASE-DEMO-001｜对照案例｜READY_FOR_REVIEW`。
2. 指出因果基线和高负荷子集两个实验。
3. 展示两条支持性 Evidence 与追溯校验。
4. 强调：`READY_FOR_REVIEW` 只代表可以进入人工复核，不代表自动批准。

## 案例三：灰区处理（35 秒）

1. 选择 `NEEDS-REVIEW-001｜灰区案例｜NEEDS_REVIEW`。
2. 指出稳定性证据“尚无定论”以及仍开放的 Evidence Gap。
3. 强调：系统不把证据不足伪装成成功或失败，而是保留不确定性并请求人工复核。

## 收束（15 秒）

“三种 Gate 对应三种真实状态：明确反证时阻断、证据闭合时进入人工复核、证据不足时保留灰区。这就是智感Nova的可信诊断价值。”
