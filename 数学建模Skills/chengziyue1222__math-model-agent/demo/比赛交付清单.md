# 智感Nova本地比赛交付清单

提交前在干净电脑上完成以下检查：

- [ ] 安装 `requirements.txt`。
- [ ] 双击 `demo\\start_demo.bat` 能打开页面。
- [ ] 三个固定案例依次得到 `BLOCKED`、`READY_FOR_REVIEW`、`NEEDS_REVIEW`。
- [ ] 导出三份 `competition_report.md`。
- [ ] 从每个对应运行目录复制 `manifest.json`、代表性 Evidence 和 ToolResult 到提交压缩包。
- [ ] 截取首屏、BLOCKED 证据链、READY_FOR_REVIEW 证据链、NEEDS_REVIEW 证据缺口四张页面截图。
- [ ] 录制并核对 `比赛演示脚本.md` 对应的演示视频。
- [ ] 包中包含 `README_DEMO.md`、本清单和源码；不包含 `.venv`、临时目录或历史密钥。

`demo/outputs/` 默认被 Git 忽略，因此经验证的运行产物必须显式复制到比赛提交包中。
