# 建模图表标准

## 图型选择

- 趋势：折线图并显示时间顺序和不确定性。
- 分布：箱线、提琴、直方或经验分布，不只显示均值。
- 模型比较：点区间图、ROC、泰勒图或成对预测图。
- 灵敏度：单参数曲线、龙卷风图或二维响应面。
- 网络与流程：节点关系图或流程图，避免交叉线和装饰元素。
- 预测：观测-预测、残差、校准、误差分布或时间外推图；明确训练/验证/测试边界。
- 优化：收敛、可行域、约束余量、风险-收益或多次运行分布；不能只展示一次最好结果。

## 格式

- 标签包含变量名和单位，图例与正文术语一致。
- 使用色盲友好配色，同时用线型或标记提供冗余编码。
- 颜色按语义角色固定：基线、比较、强调和背景在全图及全文保持一致；强调色只承担一个含义。
- 字号按最终版面检查；多面板共享尺度时保持一致。
- 常规最终字号不低于 5 pt，正文、坐标和刻度通常使用 5--8 pt；必须按最终印刷尺寸检查。
- 单栏图默认 89 mm，双栏图默认 183 mm；如赛事或期刊另有要求，以官方规范为准。
- 线图优先 PDF/SVG 矢量主稿，同时交付 450 DPI RGB PNG 校样。
- PDF 使用 TrueType 字体（`pdf.fonttype = 42`），SVG 保留可编辑文本（`svg.fonttype = "none"`）。
- 图注说明数据、方法、误差线、样本量和关键参数。
- 多面板先写设计简报并做去冗余检查；除等权证据网格外，核心面板面积通常是支持面板的 1.2--1.5 倍。

## 验证

- 从机器可读结果生成，不手工录入关键数值。
- 不用随机抽样解决渲染性能；优先栅格化数据层、透明度、hexbin 或密度表达。任何聚合、过滤或变换均写入元数据。
- 图表数量由论证需要决定，不设置最低张数；饼图、雷达图、双轴图和装饰性 3-D 图不是默认选择。
- 优化已有图时不得改变源数据、单位、筛选口径或结论方向。若改变图型、坐标尺度、聚合或归一化，记录理由并重新核对正文、表格与源数据。
- 检查坐标截断、对数尺度、缺失值、排序和异常点处理。
- 打开最终文件进行视觉检查，确认无裁切、乱码或重叠。
- 核对结论、样本量、统计量、不确定性和数据源是否与论文正文及表格一致。
- 将审查结果和源数据路径写入 `.figure.json`，使数字和图形可以追溯。
- 程序审查通过后仍须实际打开最终尺寸的 PNG 和至少一种矢量主稿；未运行的视觉检查不能记为通过。
