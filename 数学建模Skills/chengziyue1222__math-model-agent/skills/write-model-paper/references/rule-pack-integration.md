# Rule-Pack Consumer: Writing, Tables, and Layout

Consume canonical paper structure, writing style, layout, and table/numeric rule files at the repository root. Inputs: verified results, dependency analysis, figure/table/formula registries, and reference-status registry. Outputs: source, structured table source, claim usage, rendering request, and validation report.

The dependency analysis decides whether a unified-model section exists. Tables must be rendered from structured values with a shared rounding policy. Unverified references are labelled and excluded from formal delivery. Failure of structural, numeric, or layout validation blocks formal paper status.
