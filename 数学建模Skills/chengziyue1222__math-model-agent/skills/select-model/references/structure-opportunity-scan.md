# 结构机会扫描

在比较具体模型前，为每道新题执行一次扫描。它不是关键词匹配器，也不是强制套用算法；每个“是”都要写出题面、数据或推导依据，每个“否”都要说明为何不适用。

| 机会 | 要问的问题 | 采用后的写作/求解动作 | 不成立时 |
|---|---|---|---|
| 共用内核 | 两个以上子问题是否复用状态、数据、约束、几何、目标或求解器？ | 画依赖图；在正文建立“统一模型层”，后续章节只写差异。 | 各题独立建模，不硬造统一层。 |
| 降维 | 高维状态能否以时间、弧长、累计量、边界变量、比例因子或不变量表示？ | 给出一一映射/适用条件，并以残差或反例检查验证。 | 保留原变量或采用可解释的分块。 |
| 解析加数值 | 结构能否先由解析推导获得，再对无闭式部分做数值求解？ | 推导负责关系、范围和初值；数值法只承担反解、优化或仿真。 | 说明为何只能数值求解，并给出基线或独立复核。 |
| 临界事件 | 是否存在首次越界、首次碰撞、约束激活、峰值或可行边界？ | 定义连续/分段连续事件函数；粗定位后精求根；报告括号或邻域。 | 不把任意离散网格点称为临界点。 |
| 搜索前提 | 二分或单调搜索是否真的有单调性？ | 优先解析说明；再用覆盖决策域的采样、翻转检查和局部加密作辅助。 | 使用全局搜索、分段搜索或明确的多分支处理。 |
| 对称/齐次 | 变换、尺度或守恒关系是否保持问题不变？ | 明确不变量和边界条件；把减少的变量与原问题对应。 | 不从数值“看起来相等”推广为定理。 |
| 共用验证 | 多题是否依赖同一底层约束或同一结果对象？ | 底层约束验证一次并被后续问题引用；每题仍验证自己的输出。 | 分别验证，避免迁移不相干的证据。 |

输出一页以内的 `结构机会扫描`：子问题依赖、可共享内核、候选化简、被拒绝的化简和各项所需验证。它是选模依据，不进入论文的工程附录。
