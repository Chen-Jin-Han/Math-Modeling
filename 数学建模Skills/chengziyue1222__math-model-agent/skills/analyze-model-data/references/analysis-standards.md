# 数据分析标准

1. 保存原始数据校验信息，不在原文件上修改。
2. 建立数据字典：字段、类型、单位、来源、允许范围和缺失含义。
3. 区分结构性缺失、随机缺失和采集错误；记录处理理由。
4. 在切分训练/测试集之后拟合缩放、插补、编码和特征选择步骤。
5. 时间数据按时间切分；分组数据按主体分组切分，避免泄漏。
6. 根据任务同时报告主指标、基线、样本量和不确定性。
7. 回归检查残差、共线性和外推；分类检查类别不平衡、校准和阈值敏感性。
8. 多重比较应说明校正方法；因果结论需要识别假设。
9. 固定随机种子并保存软件版本、参数和数据处理日志。
10. 图表和表格必须能由代码从保存的数据重新生成。
11. 实体×时间面板至少报告零值比例、活跃实体比例、滞后一阶相关、实体间绝对相关和末段时间留出统计；无法估计的量写为 `null` 并说明原因。
12. 用于未来规划的验证窗口必须位于训练窗口之后；随机打乱切分不能作为唯一的外推证据。
13. 在建模前做可识别性与覆盖检查：目标时间、空间或人群是否落在观测支持范围内，关键变量是否有足够变化，样本结构是否能区分候选机制。
14. 缺失、异常和零值处理依据产生机制、测量过程和任务损失决定，不使用固定缺失率或统一 Z 分数作为自动删改规则。
15. 插值、模拟、专家假设和外部补充数据必须带来源标签；不得把它们改写为原始观测，也不得泄漏到最终留出集的拟合过程。
16. 面板、重复测量、分组或空间数据必须保留依赖结构；划分、重采样和不确定性估计按实体、时间、地点或事件成组进行。
