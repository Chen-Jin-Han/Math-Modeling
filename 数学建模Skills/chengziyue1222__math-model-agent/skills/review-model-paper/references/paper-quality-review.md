# 成品质量审查

先审读者可见的论文，再运行后台一致性检查。审查结论按以下顺序给出：

1. 摘要是否在一页内给出框架、逐题方法/结果/验证，而非口号或无证据数字；
2. 章节是否从问题到论证自然推进；统一模型层是否由真实复用触发；
3. 每题是否都有模型、求解和结果分析，且公式、图表前后有解释；
4. 图表是否承担不同结论、可在 A4 中读清、表格是否为三线表且只给代表结果；
5. 验证是否用约束、基线、交叉验证、灵敏度或收敛来支持相应结论；
6. 引用是否真实、相关且只用于需要外部来源的主张；
7. 参考文献、附录是否独立起页；是否无页顶运行标题、孤立标题、过小代码或连续三页失衡的纯文本/纯图；
8. 后台的数字一致性、结果来源和 PDF 布局检查是否通过。

报告中将“论文可读性问题”与“后台证据问题”分栏；后者不能原样进入论文正文。
