# Legacy command archive

This directory preserves the 56 pre-Codex command documents for historical compatibility only. They are not active Codex Skills, are not installed by `scripts/install_skills.py`, and are not recommended for new modeling work.

Use the eight standard Skills under `skills/`, starting with `$run-modeling-project` for an end-to-end project. `command-map.yaml` records the closest standard replacement for every archived command. Archived instructions may describe obsolete paths, tools, permissions, or workflows; treat them as background knowledge rather than executable policy.
