# /humanize

## 用途

只读审查学术写作的模板化表达、逻辑衔接、具体性和作者责任，不判断文本是否由 AI 创作。

## 用法

```bash
/humanize file.tex --severity high
```

## 审查维度

1. 模板化过渡与空泛套话。
2. 句式、术语和段落结构是否机械重复。
3. 结论是否有数据、模型、引用或图表支持。
4. 方法、限制和失败条件是否具体。
5. 作者判断与来源观点是否清楚区分。
6. 是否满足竞赛或期刊要求的 AI 使用披露。

## 边界

- 不声称能可靠检测 AI 作者身份。
- 不帮助规避检测、隐藏来源或删除必要披露。
- 默认只报告问题；只有用户明确请求时才修改文本。

## 输出

按位置列出证据、影响和改写建议，并区分事实核验问题与纯风格问题。
