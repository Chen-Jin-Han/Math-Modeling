# /lit-review

## 用途

开展可追溯的结构化文献综述：检索、核验元数据、主题聚类、方法比较、空白识别和 BibTeX 生成。

## 用法

```bash
/lit-review "你的研究主题"
```

## 流程

1. 将主题拆成应用、模型、数据和验证概念，记录检索式与日期。
2. 优先检索原始论文、官方数据、标准和竞赛规则。
3. 核对标题、作者、年份、出版物、DOI 和稳定链接。
4. 按方法、假设、数据、指标和局限进行聚类比较。
5. 区分来源支持的事实、基于来源的推断和待验证问题。
6. 只根据已核验元数据生成 BibTeX。

## 完整性要求

- 不得虚构文献、DOI、引语、研究结果或 BibTeX 字段。
- 无法访问全文时说明只核验到哪个层级。
- “研究空白”必须限定在已检索范围内。
- 每个关键结论附直接来源；未核验记录标记为 `UNVERIFIED`。

## 输出

提供检索记录、纳入/排除标准、主题综述、证据表、研究空白和已核验引用清单。
