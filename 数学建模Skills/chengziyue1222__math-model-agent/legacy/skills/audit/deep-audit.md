# /deep-audit

## 用途

以只读方式审查仓库的指南内容、代码质量、规则一致性和跨文件一致性，输出有证据的分级问题清单。

## 用法

```bash
/deep-audit
/deep-audit --fix
```

## 默认流程

1. 确认仓库范围和现有未提交改动。
2. 运行只读检查并收集文件、行号、复现方式和影响。
3. 合并重复问题，按 blocker/major/moderate/minor 分级。
4. 输出修复顺序、验证方法和剩余风险。

## 修改边界

- 默认只报告，不修改文件。
- 只有用户明确要求 `--fix` 时才实施修复。
- 修复时保留无关改动，每轮有明确范围和验证终点。
- 不承诺“修复所有问题”或无限循环；无法验证的项目必须标记为未验证。
