# /commit

## 用途

在明确范围内执行质量检查、创建分支、暂存和提交。推送、创建 PR 与合并属于独立的外部操作。

## 用法

```bash
/commit "你的提交信息"
```

## 默认流程

1. 检查工作树，区分用户原有改动与本次改动。
2. 运行与改动范围匹配的质量检查。
3. 仅在需要时创建功能分支。
4. 展示将要暂存的文件，确认不包含秘密或无关文件。
5. 暂存并创建本地提交。
6. 报告提交哈希、测试结果和未提交改动。

## 外部操作边界

- 只有用户明确要求时才推送分支或创建 PR。
- 默认创建草稿 PR，并在操作前重述仓库、分支和目标分支。
- 不自动合并 PR；合并必须由用户单独授权。
- 不使用 `git add .`、强制推送或破坏性重置来扩大范围。

## 参数

- `message`: 提交信息。
- 可选：`--push`、`--draft-pr`，仅在用户明确请求对应操作时使用。
