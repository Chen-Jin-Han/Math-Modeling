# /data-analysis

## 用途

执行可复现的数据分析：环境审计、数据剖析、清洗、统计或机器学习建模、验证和图表输出。

## 用法

```bash
/data-analysis dataset.csv
```

## 流程

1. 保留原始数据，建立字段、单位、来源和缺失含义的数据字典。
2. 检查重复、异常、缺失、类别不平衡和目标泄漏。
3. 先定义问题与评价指标，再选择 Python 或 R 和具体模型。
4. 在拟合插补、缩放、编码或特征选择之前划分训练/测试数据。
5. 与简单基线比较，报告样本量、不确定性、稳定性和失败条件。
6. 保存脚本、配置、清洗数据、机器可读结果和可重新生成的图表。

## 边界

- 不覆盖原始数据，不因结果不理想而任意删除异常值。
- 不把相关性写成因果关系。
- 不强制使用 R；遵循项目现有语言和用户要求。
- 记录随机种子、依赖版本和所有人工处理决定。
