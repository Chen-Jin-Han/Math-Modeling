## 关键主张的证据链模板

任何最终数字必须能回填为：`数据来源/许可` → `数据哈希` → `参数与 seed` → `算法/solver 版本` → `基线定义` → `运行命令` → `结果 JSON/图` → `验证与敏感性` → `人工确认` → `Manifest`。当前 Manifest 覆盖其中的部分环节；P0/P1 必须补上 LLM/提示、Skill、solver、人工审批和数据泄漏字段。
