## 应展示的界面

1. 学生任务首页：问题、数据来源、当前阶段与下一步。
2. 任务图与候选模型卡：适用条件、拒绝理由、基线。
3. 求解/仿真面板：参数、seed、运行状态、失败候选和限制。
4. 证据链面板：输入/产物哈希、Manifest、环境、人工确认。
5. 教师审阅页：只展示匿名项目 ID、阶段、证据、反馈和退回原因。

当前仓库没有以上 UI；视频不得将设计图当成已交付功能。若时间不足，应以可运行的本地最小界面替代高保真原型。

## 答辩高概率问题

| 问题 | 可接受回答 |
|---|---|
| 为什么不是 ChatGPT + Python？ | 因为每个结论绑定数据/代码/指标/哈希、失败记录和人工审阅；没有证据时显示未验证。 |
| 会不会替学生代做？ | 不以一键论文/最终答案为产品路径；默认展示比较、验证和教师确认，正式竞赛模式限制高风险生成。 |
| 94% 和 37% 是否真实？ | 否，均来自明确标记的合成演示及特定基线；视频会展示限定条件并补独立基线。 |
