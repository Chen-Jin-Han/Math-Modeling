# 国赛 vs 美赛差异对照表

## 基本信息

| 维度 | 国赛（CUMCM） | 美赛（MCM/ICM） |
|------|-------------|---------------|
| 全称 | 全国大学生数学建模竞赛 | MCM/ICM（数学建模竞赛/跨学科建模竞赛） |
| 语言 | 中文 | 英文 |
| 时间 | 9 月（通常周四-周日） | 2 月（通常周四-周一） |
| 时长 | 72 小时（3 天） | 96 小时（4 天） |
| 队伍人数 | 3 人 | 3 人 |
| 题目数量 | 5 选 1（A-E 题） | 6 选 1（MCM: A/B/C, ICM: D/E/F） |
| 提交格式 | PDF（部分赛区要 word） | PDF（英文，25 页限制） |

## 论文结构差异

| 章节 | 国赛 | 美赛 |
|------|------|------|
| 摘要 | 中文摘要 800-1000 字 + 关键词 | Summary Sheet（英文 250-350 词） |
| 目录 | 禁止（2026 规范第四条） | 必须（放在摘要后） |
| 问题重述 | 简写或省略 | Introduction 中简要提及 |
| 假设与符号 | 独立章节 | Assumptions + Notations 独立章 |
| 算法描述 | 流程图+文字步骤，**全文无伪代码**（附录仅完整源程序） | Algorithm 环境可接受 |
| 结论 | 总结+建议 | Memorandum（信函格式给决策者） |
| AI 使用声明 | 部分赛区要求 | 必须（Report on Use of AI） |

## 评阅标准差异

| 标准 | 国赛 | 美赛 |
|------|------|------|
| 问题分析深度 | ★★★ 非常重要 | ★★ 一般 |
| 模型创新性 | ★★ 重要 | ★★★ 非常重要 |
| 结果合理性 | ★★★ 非常重要 | ★★★ 非常重要 |
| 论文清晰度 | ★★★ 非常重要 | ★★★ 非常重要 |
| 英文表达 | 不适用 | ★★★ 非常重要 |
| 可视化质量 | ★★ 重要 | ★★★ 重要 |
| 真实数据获取 | ★★★ 加分项 | ★ 一般加分 |
| 跨场景泛化 | ★ 一般 | ★★★ 加分项 |

## 写作风格差异

| 维度 | 国赛 | 美赛 |
|------|------|------|
| 语言要求 | 准确、简洁、专业的中文 | 清晰、有说服力的英文学术写作 |
| 摘要重点 | 模型+方法+结果+灵敏度 | 方法占比最大（45-55%）+ 2-3 个量化结果 |
| 模型描述 | 注重算法流程和数学推导 | 重视创新点和模型选型理由 |
| 结果呈现 | 数据+表格+分析 | 图表+文字解读+趋势判断 |
| 参考文献 | 10-15 篇，中英文结合 | 15 篇左右，英文为主 |

## 常用算法倾向

| 问题类型 | 国赛常见方法 | 美赛常见方法 |
|---------|------------|------------|
| 物理/工程问题 | 微分方程、有限元、优化 | 机理建模 + 数值仿真 |
| 数据处理 | 插值拟合、回归分析 | 统计检验 + ML 方法 |
| 优化问题 | 线性/整数规划、遗传算法 | 多目标优化、动态规划 |
| 评价/决策 | AHP、TOPSIS、熵权法 | 层次分析 + 灵敏度分析 |
| 预测问题 | 灰色预测、时间序列 | ML 方法、状态空间模型 |
| 分类/识别 | SVM、决策树 | 贝叶斯网络、集成方法 |

## 格式硬性要求

### 国赛
- 正文（正文主体 + AI 声明 + 参考文献）≤30 页（2026 规范第四条硬门禁；不得含目录）；**30 页是上限非目标**
- 附录页数全国规范不限（湖南赛区限额 ≤20 页）；支撑材料清单置附录首页
- 摘要专用页含题名+摘要+关键词，≤1 页；电子版第一页=摘要专用页
- 页码从摘要专用页起编、页脚中部、阿拉伯数字从 1 开始连续编号（摘要页=第 1 页，2026 规范第三条）
- 提交 PDF 文本型（非图片/扫描）、≤20MB
- 正文宋体/ Times New Roman，小四号字

### 美赛
- 总页数不超过 25 页（含摘要、目录、正文、参考文献、AI 声明）
- Summary Sheet 为第一页
- 字号 11-12pt
- Letter 尺寸纸张（8.5x11 英寸）
