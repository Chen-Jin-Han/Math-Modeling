%  3. 内容必须自包含：不依赖其他部件中定义的文字/内容；\ref 可跨部件引用
%     （label 前缀保证了不冲突），但文字叙述不得引用其他部件的内容。
%  4. 引用机制必须与主论文一致：主论文默认 \scite{编号}（位置式，定义在模板
%     preamble），本文件禁止混用 \cite{key}（键式）——组装前由 citecheck.py 拦截。
