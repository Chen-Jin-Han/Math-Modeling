# 国赛/美赛格式检查表

## 国赛格式检查

- [ ] 摘要专用页（电子版第一页）含题名 + 摘要内容 + 关键词，且 ≤1 页？（2026 规范第三条；题名居中置页顶）
- [ ] 关键词是否 3-5 个？
- [ ] 字体要求（宋体/Times New Roman）？
- [ ] 字号（小四号/12pt）？
- [ ] 公式编号连续且规范？
- [ ] 表格是否为三线表？
- [ ] 图标题在图下方、表标题在表上方？
- [ ] 参考文献格式统一？（GB/T 7714 推荐）
- [ ] 正文/附录均无伪代码？（算法用流程图+文字步骤表达；附录仅完整可运行源程序）
- [ ] 算法是否有流程图？
- [ ] 理论部分是否含流程图 + 算法三线表？
- [ ] 结果部分是否误用流程图（结果只放数据可视化）？
- [ ] 所有变量是否定义清楚？
- [ ] **正文（正文主体 + AI 声明 + 参考文献，不含摘要/附录）≤30 页？**（2026 规范第四条；30 页为上限，26-30 为目标区间）
- [ ] **不得包含目录？**（2026 规范第四条，模板 `% \tableofcontents` 勿启用）
- [ ] 附录 ≤20 页（湖南赛区限额；全国规范页数不限）？**支撑材料清单置附录首页**？
- [ ] 页码从摘要专用页起编、页脚中部、阿拉伯数字从 1 开始连续编号？（2026 规范第三条；摘要页=第 1 页）
- [ ] 电子版第一页为摘要专用页（含题名+关键词；无承诺书/编号页，`withoutpreface`）？
- [ ] 提交 PDF 为**文本型**（非图片/扫描合成）且 ≤20MB？支撑材料压缩包 RAR/ZIP ≤20MB？
- [ ] **AI 工具使用声明是否在参考文献【之前】？（2026 年试行规定，`\CumcmAIUsed`；含"已使用……详细使用情况见支撑材料"，用途与实际一致）**
- [ ] **支撑材料是否附《AI工具使用详情.pdf》？（文件名固定，4 项内容 + 5 条人工核验清单，不得含姓名/学校/赛区；缺文件按违规处理）**

## 美赛格式检查

- [ ] 总页数是否 ≤25 页（含所有内容）？
- [ ] Summary Sheet 是否在第一页？
- [ ] 目录是否在第二页？
- [ ] 纸张尺寸是否为 Letter（8.5x11 英寸）？
- [ ] 字号是否 ≥11pt？
- [ ] 摘要是否 250-350 词？
- [ ] 每个子问题是否独立成章？
- [ ] 图表编号是否连续（Figure 1-XX, Table 1-XX）？
- [ ] 所有图表在正文中是否有引用？
- [ ] 参考文献格式统一排列？
- [ ] 标题是否在 Summar Sheet 第一行？
- [ ] 队伍编号是否在每页页眉？
- [ ] Memorandum（信函）是否单独成章？
- [ ] Report on Use of AI 是否包含？（内容由用户自行记录提供，AI 只协助排版）
- [ ] 是否说明所有数据来源？
