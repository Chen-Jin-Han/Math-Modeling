# 各阶段质量门检查清单

## Phase 0：初始化

- [ ] 比赛模式已检测并获用户确认（国赛/美赛/通用，无明确倾向时默认国赛）？
- [ ] 技术栈已锁定（Python/MATLAB/LINGO/R，用户确认，不代选）？
- [ ] 依赖 skill 状态明确（缺失项已说明功能+为什么需要+安装方式）？
- [ ] 需求四项已逐条确认（题目理解/方法偏好/数据情况/输出要求）？
- [ ] 项目文件夹位置已与用户确认（**未确认前不创建任何项目目录**）？
- [ ] **备份纪律已宣讲并确认**（每日至少一次完整备份到非本机位置；阶段过渡与 Phase 3 每片结束各备份一次；备份位置写入 checkpoint）？

## Phase 0.5：题目信息获取

- [ ] 每个输入文件都有抽取结果，且状态明确（成功/空/扫描版）？
- [ ] **题目读取以视觉识读为主（转图直接看页，模型具备多模态），extract_input.py 等脚本仅用于精确数字抽取？纯文本异常时已用视觉页验证？**
- [ ] 题目原文完整无删改？
- [ ] 关键数字、数据表齐全？
- [ ] **有数据表时，变量字典（字段名/含义/单位/缺失异常值）是否已抽取？**
- [ ] 存疑项已列清单并给出处理建议？
- [ ] 用户已确认信息卡内容？

## Phase 1：问题分析

- [ ] 题目拆解是否覆盖所有子问题？
- [ ] 每个假设是否都含合理性说明？
- [ ] 假设是否讨论了不满足的后果？
- [ ] 数据需求是否明确定义？
- [ ] 关键约束是否识别？
- [ ] **硬约束清单是否逐字摘录（不转述）？**
- [ ] **关键统计数字是否有探索输出文件支撑？**
- [ ] **出口交互门是否执行（用户确认无补充后才通过）？**
- [ ] **思考路径节是否每个子问题四步齐全（观察点/试探与发现/解决与转化/引申一问）？**
- [ ] **思考路径节是否含 ≥1 个转折点、不以结论开头？**
- [ ] **思考路径节是否落到公式层（理论核心公式 + 代入本题参数的计算）？**

## Phase 2：模型设计

- [ ] 每个子问题是否≥2 种方案对比？
- [ ] 是否说明了 Why 而非只说了 What？
- [ ] 数学表达是否完整（变量+函数+约束）？
- [ ] 是否提供了学习资源（仅当用户提问时）？
- [ ] 方案选择是否经过用户确认？
- [ ] **方案前交互门（补充约束确认）与方案后确认（选哪个）是否执行？**
- [ ] **每个候选方案是否有创新点阐述（标准方法无创新时是否给出：如何创新/为什么好/如何实现/难度）？**
- [ ] **选定方案后是否产出创新点陈述（灵感+核心构成+与常规区别）并写入 checkpoint？**
- [ ] **思考路径节是否衔接 Phase 1 叙事（首句"上一阶段我们发现……"）？**
- [ ] **思考路径节是否覆盖完整决策链（候选为何提出/为何被否被选/转折点）且落到公式层？**

## Phase 3：建模实现

- [ ] 代码是否可运行？
- [ ] 依赖声明是否完整（库名+版本）？
- [ ] **复现清单.md 是否已产出（固定种子 + 输入文件 SHA-256 + 环境版本 + 唯一复现命令）？**
- [ ] 结果是否通过了合理性检查（数量级+边界）？
- [ ] 可视化是否规范（图注+坐标轴+配色）？**国赛图表文字是否全中文（坐标轴/图例/标题/刻度无英文）？**
- [ ] **流程图/示意图不限于 TikZ（drawio/任意工具均可），但每张图是否均附设计思路说明（结构/元素/连线/布局意图，供用户手搓）？**
- [ ] **出图流程是否走完：图需求单（类型/数据来源/坐标轴/想讲什么/论文位置/配色）→ 用户确认 → 画图 → 视觉自检（模型 Read 图自查：无豆腐块/无重叠/字号 ≥8pt/色盲友好）→ 入图？不合格重画是否 ≤2 轮？**
- [ ] **每张图是否先明确「想讲什么」并写入 docs/figure-notes.md（一图一问 + 为什么这样呈现，不进正文）？图间信息是否无重复？**
- [ ] **图是否按角色分类（诊断/过程/结果）？诊断图是否未混入论文选图？结果图是否每子问题 ≥1？**
- [ ] **配色是否避免红绿并列（色盲友好）？**（可用 slanCM/ColorBrewer 离散色卡落地）
- [ ] 关键参数是否集中配置、不硬编码？
- [ ] 代码是否被审查过？
- [ ] **硬约束-代码实现对照表（code_consistency）是否已产出（每条硬约束 → 文件:行/实现方式/有无违背）？**
- [ ] **docs/result-trace.md 是否已产出（每个量化结果 → 代码输出文件 + 表/图号溯源行）？**
- [ ] **人工代码检查（checklists/code-human-review.md）是否已执行并记录结论到 checkpoint code_review 段？不通过是否已回改重审（旧 PASS 失效）？**（门禁不过不得进入 Phase 4）
- [ ] **冒烟测试是否先于全量运行（1% 规模跑通 + 硬约束核对）？**
- [ ] **长任务是否拆片（>30min → ≤40min 片 + checkpoint 断点续算）？**
- [ ] **每片结束是否已完成一次项目目录备份（Phase 0 确认的备份位置）？**
- [ ] **每片结束是否向用户汇报（进度/问题/原因/解决计划）？**
- [ ] **图注（类型/库/函数/参数）是否不在图内、不进正文？**
- [ ] **制图是否 MATLAB 优先？**
- [ ] **MATLAB 工具箱是否已确认（ver 检测），代码是否只用已装功能？缺工具箱时已上报用户（功能+为什么需要+安装方式）或改写避开？**

## Phase 4：论文写作

- [ ] 摘要结构是否完整（数据→模型→结论→灵敏度→意义）？
- [ ] **国赛摘要是否 ≤ 摘要专用页 1 页不跨页（页内含题名+关键词，题名见模板首页结构）？800-1000 字为建议值非硬门禁？**
- [ ] 方法篇幅:结果篇幅 ≤ 1:1？每段至少 1-2 个量化结果？
- [ ] 关键词是否全为模型名/方法名（无通用词）？
- [ ] 是否有明显的 AI 痕迹段落需要修改？
- [ ] 每张图表后是否有分析文字段落？
- [ ] 每张图/表在正文中是否有显式引用？
- [ ] 参考文献是否真实可查？正文中是否有引用标记？
- [ ] **国赛文献 ≥8 篇（常见 10-15，建议值）？** 红线=真实性：宁少勿假，真实 6 篇 > 凑数 20 篇，严禁为凑数编造（与红线 2 一致）
- [ ] 每处引用是否说明了"引了什么+为什么引"？
- [ ] **引用文献的结论是否限定在作者验证过的适用域？未验证场景是否未写成"普遍适用/优于全部"？**
- [ ] 国赛：算法是用流程图呈现而非伪代码？
- [ ] 美赛：Summary Sheet 是否符合 250-350 词规范？
- [ ] 每个假设是否附了合理性论证？
- [ ] 章节间是否有承上启下的过渡？
- [ ] 模型评价是否有量化指标？
- [ ] **结果讨论是否含偏置分析（数据/模型/计算偏置）与局限性说明？（美赛偏重：对应官方评分 Result and Bias Analysis；国赛以误差/灵敏度/稳健性三大检验为主）**
- [ ] 全篇公式是否都有编号和引导句？
- [ ] 全文术语是否一致（同一概念不出现两个说法）？
- [ ] 错别字高危对是否全查（推荐→准荐、模型→模形、假设→假设[字形错]、证明→明证、即→既/既→即）？
- [ ] **写作前必读是否按赛区完成（美赛：2401445 必读 + 同题型 1-2 篇按需；国赛：检索相关 1-2 篇）？跳过篇目是否写明理由？**
- [ ] **是否已输出语言锁定声明且全文规范一致（中英不混用）？**
- [ ] **每个问题是否按理论/结果二分撰写（理论含流程图+三线表，结果仅数据可视化）？**
- [ ] **结果部分是否误用流程图？**
- [ ] **\cref 引用是否统一（图/表/公式/假设/章节一律 \cref），且 \cref 前没有"图/表/公式/假设/章节"等冗余前缀词？**
- [ ] **中文引号是否用 “”（非英式直引号）？**
- [ ] **符号说明是否直接三线表且不参与编号？**
- [ ] **三线表是否都有 `\setlength{\tabcolsep}{}`？**
- [ ] **间距统一（硬门禁，用户强调）：假设环境内部/假设与正文/段落间/章节间距全文一致（无空行/\\/itemize 额外间距），逐页抽查？**
- [ ] **长表是否已处理（>12 数据行或超半页 → 核心列+附录或整体附录）？**
- [ ] **摘要公式数量是否在限制内（国赛 ≤2 / 美赛 ≤3）？**
- [ ] **多人模式：paper-framework.md 是否先于部件生成且每个分发文件夹有副本？交回/ 目录是否已创建？**
- [ ] **正文是否无"创新点/我们创新地"字样（创新强调只在 Phase 2 给方案时）？**
- [ ] **内容去重：正文内有无跨章节无增量重复叙述？**
- [ ] **references-notes.md 是否已生成（每篇文献：标题 | 来源网站+检索词+日期 | 用了什么思维）？**
- [ ] **flowchart-notes.md 是否已生成（每张流程图一个要点块）？**
- [ ] **tex 注释是否精简（每节只留 1 行锚点注释，无解释性绿注释）？**
- [ ] **用户是否说"要写 AI 使用报告"并提供记录文本？**已提供 → AI 只填不改生成详情 PDF、与正文声明核对一致；未提供 → 不提醒、不代记（用户自理）
- [ ] **页数预算表是否已确认并写入 checkpoint？**（单位预算 + 三问按贡献 4:3:3/5:3:2；多人模式下各部件预算写入 background/README）
- [ ] **每问是否都有「本问定位句」？**（1-2 句：与常规做法差异=新意所在 + 本问关键结论数值）
- [ ] **检验小节是否已合并**（≤5-6 个）？每章过渡句 ≤2 句（无三段式强积）？

- [ ] 参考文献完整且格式统一？每篇在正文中有引用？

### AI 合规与真实性核查（2026 国赛新规，语义检查，不代删改）

- [ ] **AI 声明位置（机械确认）**：国赛正文「AI 工具使用声明」在参考文献【之前】（`\CumcmAIUsed` 位置）？
- [ ] **详情 PDF（机械确认，必带项）**：支撑材料存在 `AI工具使用详情.pdf`，含 4 项内容 + 5 条人工核验清单，无姓名/学校/赛区（文件名固定；缺文件判不通过，提示用 `ai-usage-detail-template.tex` 生成）？
- [ ] **AI 痕迹检测**：核心建模段（模型构建/公式推导/机理分析/求解逻辑）与核心写作段（摘要/结论/对应分析）是否存在可判定的 AI 主导生成痕迹？有则**提示用户自决修改**（AI 不代删改、不代记）
- [ ] **AI 声明匹配**：全文 AI 使用痕迹与论文 AI 使用声明是否一致（无瞒报/漏报/虚假声明/用途不符）？
- [ ] **AI 内容人工核验**：AI 生成段落是否有场景适配与人工打磨痕迹（识别原生未修改直出）？
- [ ] **数据真实性**：数据仅来自原题（无虚构/篡改/私自新增/修改数据精度）；文献与行业结论真实；图表数值与代码输出/原始数据一致（三方核对之外确认"来源"维度）
- [ ] **逻辑因果性**：无强行关联/虚假因果/无依据得出结论
- [ ] **匿名合规**：全文无学校/姓名/队伍/隐私信息（国赛匿名评审）
- [ ] **三大检验齐全**：误差分析（相对/平均误差/RMSE + 误差来源与可控范围说明）+ 灵敏度分析（参数 ±10-20% + 权重维度）+ 稳健性分析（结论对参数/样本/假设变化的稳健）
