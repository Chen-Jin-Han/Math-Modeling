# 模型选择教学指南（国赛四大题型）

> **定位**：教学参考——只在用户需要"这类题通常有哪些选择、为什么"时提供。**不代用户选模型**（红线 1：方案对比仍须 ≥2 种且说 Why，最终由用户拍板）；学习途径默认不写、用户提问时给。符号用 Unicode（σ̂、R²、CR），不用 LaTeX 命令。来源：2026 国赛速通教程四大题型标准流程与模型适用表 + 提示词汇总检验清单，经提炼（过滤营销话术与"高分描述"模板）。

## 0. 题型判定：一句话归类

| 题型 | 判定依据（一句话） | 出现频率 |
|---|---|---|
| 优化类 | 有决策变量 + 目标函数 + 约束 → 求最优决策 | 必考题（每年至少一个子问） |
| 评价类 | 多个待比对象 + 指标体系 + 权重 → 排序/分级 | 高频 |
| 预测类 | 历史观测数据 → 外推趋势/估计未知数值 | 高频 |
| 机理分析类 | 物理/化学/生命/经济规律 → 建立微分/代数方程 | A 题专属高频 |
| 辅助类（统计） | 相关/拟合/假设检验/聚类 | 视题目 |
| 辅助类（网络与图） | 节点-边结构 → 路径/连通/分配 | 视题目 |
| 辅助类（数据处理） | 大数据/高维/缺值 → 清洗、特征工程、降维 | C 题高频 |

## 1. 各题型标准流程（答题骨架）

- **优化类**（标准六步）：定目标 → 提决策变量 → 理约束 → 建模型框架（线性→线性规划；非线性→非线性规划；整数/0-1→整数规划；多目标→多目标规划；分阶段→动态规划）→ 选算法（凸问题：梯度/内点；非凸复杂：GA/粒子群/模拟退火）→ 结果分析+灵敏度检验
- **评价类**（标准五步）：构建指标体系（全面/独立/可量化）→ 指标预处理（正向化/无量纲化/去异常）→ 定权重（主观 AHP / 客观熵权/变异系数 / 组合加权）→ 综合排序（TOPSIS/模糊综合/DEA/灰色关联）→ 结果排序+稳健性检验
- **预测类**（标准五步）：明确目标与周期 → 数据预处理（缺值/异常/平稳化）→ 选模型（小样本 GM(1,1)；时序 ARIMA/指数平滑；回归 Lasso/岭；机器学习 随机森林/XGBoost）→ 模型检验（R²/残差/MAPE-RMSE）→ 区间预测+结果分析
- **机理分析类**（标准五步）：物理/工程背景分析 → 基本定律提取（牛顿/能量/质量守恒/传热）→ 建立微分方程 → 求解（解析解/数值解：RK45、龙格-库塔、有限差分）→ 参数分析+灵敏度检验
- **数据处理**（标准五步，多作前置）：EDA 探查（描述统计/缺失/异常）→ 清洗（缺值 <5% 均值中位；5-30% 插值；>30% 预测填充；异常 3σ/箱线图/LOF）→ 规范化（标准化/归一化/编码/离散化）→ 特征工程（相关性/共线性剔除、PCA/关键特征筛选）→ 建模分析

## 2. 模型适用速查（场景 → 算法 → 必修检验）

### 优化类

| 场景 | 推荐算法 | 必修检验 |
|---|---|---|
| 线性约束、连续变量 | 单纯形/Lingo | 可行解存在性；最优性（无解/退化/无可行解） |
| 整数/0-1 决策 | 分支定界/割平面 | 松弛界限合；上下界收敛即最优性 |
| 非线性目标/约束 | 拟牛顿/GA/粒子群 | 迭代收敛曲线；局部/全局最优验证（多初值） |
| 多目标相互矛盾 | 权重法/NSGA-II | 帕累托前沿有效性；权重敏感性；多目标均衡性 |
| 组合/路径/调度 | 遗传算法/ACO/模拟退火 | 迭代收敛曲线；多次运行稳定性；最优解偏差分析（对比精确解/贪心/松弛下界） |

### 评价类

| 场景 | 推荐算法 | 必修检验 |
|---|---|---|
| 无大量客观数据、靠专家经验 | AHP（层次分析法） | **一致性检验 CR<0.1（核心必做）**；判断矩阵归一化 |
| 有完整量化数据、数据自身差异赋权 | 熵权法/CRITIC/变异系数 | 指标正向性；信息熵/离散度校验；剔除差异过小指标 |
| 多指标多对象精确排序 | 熵权+TOPSIS/灰色关联 | 正负理想解计算校验；贴近度排序验证；结果合理性分析 |
| 大量模糊判断 | 模糊综合评价 FCE | 评语集构建；隶属度矩阵校验；模糊算子合成 |
| 高维/非线性评价 | BP 神经网络/随机森林 | 样本集划分；K 折交叉；MSE/MAE；评价结果稳定 |

### 预测类

| 场景 | 推荐算法 | 必修检验 |
|---|---|---|
| 小样本、贫信息（短时序） | 灰色 GM(1,1) | 级比检验；后验差检验（精度等级）；残差检验；马尔可夫状态修正（组合） |
| 连续时序、周期平稳 | ARIMA/SARIMA/Prophet | ADF 平稳性；白噪声；残差正态；季节分解校正；**AIC/BIC 择优** |
| 多因素连续预测 | 多元回归（Lasso/岭） | **VIF 多重共线性；F/t 显著性；残差；拟合优度 R²；系数 t 检验** |
| 大数据、非线性趋势 | 随机森林/XGBoost/LSTM | 训练/测试合理划分；K 折；过拟合检验；MSE/MAE 误差；特征重要性 |

### 机理分析类

| 场景 | 推荐算法 | 必修检验 |
|---|---|---|
| 因果（时序数据） | 格兰杰因果/中介效应 | 变量平稳化；显著 p 值；规避伪相关（截数据不可用） |
| 动态演化规律 | Logistic/SIR/ODE 数值解 | 初值/边界合理性；模型拟合度（RMSE/拟合曲线对比）；动态趋势稳定性；参数物理意义 |
| 复杂系统结构关系 | 结构方程 SEM/路径分析 | 模型适配度（RMSEA/CFI/TLI）；路径显著性；多重共线性 |
| 长期动态+反馈 | 系统动力学 SD | 因果回路合理性；存量流量方程校验；仿真历史拟合；灵敏度 |

### 聚类与统计（辅助）

| 场景 | 推荐算法 | 必修检验 |
|---|---|---|
| 无标签数据分组 | K-Means/层次聚类 | 肘部法定 K；轮廓系数/组内相似度；稳定性 |
| 高维不规则数据 | DBSCAN | 邻域参数 eps/最小点数调参；噪声样本识别；密度一致性 |
| 相关分析 | Pearson/Spearman/Kendall | 数据正态性（Pearson 专用）；相关性显著性 p 值 |
| 分类（有标签） | 逻辑回归/SVM/随机森林 | 混淆矩阵准确率/召回率/F1；ROC-AUC；过拟合/泛化能力 |

## 3. 通用检验要点（不论题型）

- **灵敏度**：关键参数 ±10%/±20% 变动，观察结果变化幅度（幅度小→模型稳健；幅度大→敏感性分析是加分项）；主观权重做权重灵敏度
- **误差分析**：相对误差/平均误差/RMSE，必须说明误差来源与可控范围（不可只说数字）
- **稳健性**：结论对参数/样本/假设变化的稳健性，替代数据/替代方法验证
- **随机类模型（MC/启发式）**：样本量收敛性（N 翻倍结果稳定）、固定随机种子可复现、CRN 方差削减（若多场景对比）
- **模型选择理由**：为什么不用别的（1-2 句），评阅看到的是有意识的选择

## 4. 创新点二分类（教学参考）

创新方向只有两类，标准方法够用则不硬创新（红线 1：创新点只是建议，不代用户决定）：

**① 方法间组合** —— 把多个模型/方法按本题结构拼起来，各取所长：
- 多模型对比择优（两个模型结果互验/择优，论证充分性）
- 同领域融合（互补短板：ARIMA-线性趋势 + LSTM-非线性波动；AHP-主观 + 熵权-客观；GA-全局 + 局部搜索）
- 跨领域迁移（把别的领域成熟机理迁到本题：信息扩散→传染病 SIR；竞争博弈→种群模型；交通流→流体力学）

**② 方法改良** —— 对经典方法做针对性修改，使其贴合本题特点：
- 参数自适应（固定参数→自适应/动态权，如自适应 PSO/灰色 GM(1,1) 参数动态修正）
- 求解算法升级（标准算法→更适合本题的算法：改进全局搜索/收敛性）
- 经典步骤改写（按本题的特殊约束/口径重新定义判定条件、分段处理等）

**判断**：组合与改良都是为了"更贴合本题"，不是为炫技；选哪个由用户权衡（教学空间可展开讲）。
