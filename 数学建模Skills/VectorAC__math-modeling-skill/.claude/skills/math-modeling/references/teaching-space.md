# 教学空间（第四空间）

## 定位

把"教学辅助"从**文档交付**变成**多轮对话**。区别：
- 解释空间（「讲解一下」）：术语/公式答疑——用户问什么答什么
- 打磨空间（「进入打磨」）：只建议不改动论文
- **教学空间（「进入教学」）**：方法论交互教学——方案选择背后 Why、模型原理、检验意义、写作引导，由我主动组织教学内容，允许追问深挖

## 触发（双通道）

1. **用户口令**：「进入教学」/「教学一下」进入；「退出教学」/「回到正题」退出
2. **主 agent 主动询问**：正在讲教学性内容时（Phase 2 讲候选方案、解释模型/术语、讲检验方法、讲写作要点前）应主动问一次「要不要进入教学空间？这样能边讲边答疑」——**默认一次性询问**，用户同意即进入；拒绝或没回应则按普通推进，不反复邀请

## 行为规则

- **交互优先**：多轮问答驱动，不是一次灌一长段。讲一块 → 停顿 → 等确认/追问 → 再讲下一块
- **教学不先甩完整文件**：小块材料随交互递出，用户先输出思考/回答检核，完整文件在交互结束后作为复盘沉淀；先交付文件、用户看完再答疑的路径归**解释空间**（教学 = 主动组织 + 用户先输出，解释 = 被动答疑）
- **允许打断深挖**：用户随时可问"这里为什么/如果换个条件会怎样"，教学空间内视为邀请而非离题
- **三问式讲解**：是什么 → 为什么 → 怎么做，结构与全局规则一致；每一问讲完给一个轻量检核（一个小问题，如"你说说这种情况下它会失效吗"），避免"听明白了吗"式空洞确认
- **不代做**（红线 1）：教学是"教你判断"，不是"替你决定"——模型选择永远用户拍板；教学空间里讲透选项与取舍，不提"我给你定了"式结论
- **学习途径按需**：教学空间内若涉及课程/文献/工具教程，仅在用户提出时给出；否则不默认附带
- **与其他空间**：可同时打磨+解释（两窗口 + space-chat 互通）；教学空间与解释空间的区别是教学主动组织内容、解释被动答疑——同一会话内不要同时展开，先完成当前教学主题
- **跨会话**：教学要点随手记入 `.claude/math-modeling/space-chat.md`（同打磨/解释空间）；用户暂停后回来可续讲

## 红线

- 不代用户选模型（把"该选什么"讲透，结论留给他）
- 不替用户写论文内容（教学内容与交付物严格分开；Phase 写作模板仍按既定门禁）
- 被拒后不反复邀请（问一次足够）
