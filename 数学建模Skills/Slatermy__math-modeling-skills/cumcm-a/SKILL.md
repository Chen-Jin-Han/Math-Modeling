# 数模国赛 A 题：物理/工程/机理建模

A 题通常是物理或工程背景，本质是**把实际物理过程"翻译"成数学语言（微分方程），再数值求解**。不要一上来写代码——先做机理分析。

---

## 一、通用解题流程（5 步）

1. **机理分析**：读懂物理过程，逐句把条件翻译成数学规则
   - "自由下落" → 重力加速度匀加速
   - "压力稳定" → 进油量 = 出油量（守恒）
   - "匀速直线" → 位置 = 初位置 + 速度 × 时间
2. **建坐标系 + 定义变量**：选合适坐标系（直角/极/柱/球），定义状态变量（位移 x、速度 v、压力 P、流量 Q、温度 T、浓度 c……）
3. **列微分方程**：由守恒律/物理定律得到方程（见下方"物理定律速查"）
4. **初值 + 边界/分段条件**：初始时刻、阀门周期、投放时刻等都写成初值或分段条件
5. **数值求解 + 参数优化**：ODE 求解器数值积分；若要求"最优参数"，结合网格搜索/二分法/非线性优化

---

## 二、物理定律速查（列方程用）

| 现象 | 定律 | 典型方程 |
|---|---|---|
| 质点运动 | 牛顿第二定律 | `m·x'' = F` |
| 质量/流量 | 质量守恒 | `d(ρV)/dt = 流入 − 流出` |
| 热传导 | 傅里叶定律 | `∂T/∂t = α·∂²T/∂x²` |
| 扩散 | 菲克定律 | `∂c/∂t = D·∂²c/∂x²` |
| 电路 | 基尔霍夫 | RLC：`L·q'' + R·q' + q/C = U(t)` |
| 振动 | 简谐/阻尼 | `x'' + 2ζω·x' + ω²·x = 0` |
| 流体 | 伯努利/连续性 | `P + ½ρv² + ρgh = const` |
| 能量 | 能量守恒 | 动能 + 势能 + 内能 = 常数 |

**核心思想：守恒律是 A 题的万能起点**——质量、动量、能量守恒，把"流入流出"写成微分方程。

---

## 三、微分方程分类与解法

| 类型 | 特征 | 解法 |
|---|---|---|
| 一阶 ODE 初值 | dy/dt = f(t,y) | RK4（ode45 / solve_ivp / odeint） |
| 高阶 ODE | 含 y'' 等 | **降阶**：令 v=y'，化为一阶方程组再数值积分 |
| 常系数线性 | 特征方程 | 解析解（e 指数 + 特解） |
| 偏微分 PDE | 含 ∂/∂x | 有限差分法离散化 → 大型代数方程组 |
| 边界值问题 BVP | 两端都有条件 | 打靶法（shooting）或有限差分 |

**降阶示例**（二阶 → 一阶方程组）：
```
x'' = f(t, x, x')   →   令 v = x'
                        x' = v
                        v' = f(t, x, v)
```

## 四、数值方法（Python 模板）

### 1. ODE 初值问题（首选 `scipy.integrate.solve_ivp`）
```python
import numpy as np
from scipy.integrate import solve_ivp

def f(t, y, *params):      # y 是状态向量
    x, v = y
    return [v, -k*x - c*v]   # 阻尼振动：x'' = -k x - c x'

sol = solve_ivp(f, [0, 10], [1.0, 0.0], args=(k, c),
                t_eval=np.linspace(0, 10, 1000), method="RK45")
t, x = sol.t, sol.y[0]
```

### 2. 参数辨识 / 最优参数（网格搜索 + 优化）
```python
from scipy.optimize import minimize_scalar, curve_fit

# 网格搜索：找使目标最小的参数
best = min((candidate for candidate in np.linspace(a, b, 1000)),
           key=lambda p: objective(p))

# 数据拟合：已知模型 y=f(x,p)，估计参数 p
popt, _ = curve_fit(f, xdata, ydata, p0=初始猜测)
```

### 3. 偏微分方程（有限差分，一维热传导示例）
```python
# ∂T/∂t = α ∂²T/∂x²，显式差分
for n in range(Nt):
    T_new[1:-1] = T[1:-1] + alpha*dt/dx**2 * (T[2:] - 2*T[1:-1] + T[:-2])
    T = T_new
# 稳定性条件：alpha*dt/dx**2 <= 0.5
```

### 4. 非线性方程 / 方程组求根
```python

```

## 五、历年 A 题典型案例（套路印证）

| 年份 | 题目 | 核心模型 | 关键点 |

## 六、常见坑位

1. 单位不统一（m/s vs km/h，MPa vs Pa）——先统一到 SI
2. 高阶方程忘了降阶，直接塞给求解器
3. 忘记写初值/边界条件，或分段条件漏掉
4. 数值方法稳定性（显式差分 dt/dx² 过大发散）
5. 参数优化没有验证最优性（只找到局部最优）
6. 物理量正负号/方向搞反（受力、速度方向）
7. 只给曲线不给关键数值（如"稳定压力约 100 MPa"要写出具体数）

## 七、A 题答题要点（论文里要体现）

- 每个模型**先说清物理机理**（用了哪条守恒律/定律），再列方程
- 方程**编号**，符号进符号说明表
- 数值结果要**验证**：与常识/量纲/特例对照（如参数趋于 0 时退化为已知解）
- 敏感性分析：物理参数（阻尼、流速、温度）扰动后结果变化
- 结论要落到"物理意义"（压力是否稳定、遮蔽多久、功率多大）
