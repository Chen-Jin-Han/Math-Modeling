## 使用方法

1. 从上表选择项目，阅读该项目的原始 README。
2. 按项目说明安装依赖、配置工具或选用对应的 Skill。
3. 运行代码、使用模板及引用资料时，遵循该项目的使用说明和许可条款。

## 来源与版本

本次收录包含各项目默认分支在表中提交版本的全部 Git 跟踪文件。各项目按原始目录结构保存，Git 历史由原始仓库维护。

[UPSTREAM_SOURCES.json](UPSTREAM_SOURCES.json) 记录获取时间、来源地址、分支、完整提交号、文件路径、Git 文件模式、文件大小及 SHA-256，可用于逐文件核对和后续更新。

更新合集时，以每个项目的原始仓库为准，记录新提交号并同步更新来源清单及文件校验值。
