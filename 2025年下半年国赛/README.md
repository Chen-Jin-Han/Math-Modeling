# 2025年下半年国赛

项目论文题为“基于多阶段混合优化算法的无人机投放烟幕弹遮蔽研究”。研究通过运动学建模、事件驱动时间细化和多阶段全局/局部优化，为多架无人机、多枚烟幕弹和多枚来袭导弹设计协同遮蔽策略。

## 目录结构

- `题目及相关附件/`：当前为空；原 `A题.pdf` 已由维护者主动删除。
- `论文/`：Word 源稿、最终 PDF 与另一份论文 PDF 版本。
- `论文补充材料和附件/`：五问 Python 代码、结果表、论文插图、AI 工具使用说明及支撑材料压缩包。

## 模型与方法

- 导弹、无人机与烟幕云团运动学模型
- 严格 L3 遮蔽判据与事件驱动时间细化
- DIRECT、差分进化、模式搜索和粒子群优化
- 多无人机/多烟幕弹任务分配与协同优化

## 代码运行

进入 `论文补充材料和附件/A题支撑材料` 后，按问题顺序运行：

```powershell
python Problem1.py
python Problem2.py
python Problem3.py
python Problem4.py
python Problem5.py
```

代码使用 `numpy`、`pandas`、`scipy` 和 `matplotlib`；写入 Excel 时还需要 `openpyxl`。项目未提供锁定版本的依赖文件，建议在独立虚拟环境中安装。部分脚本计算量较大，并可能在当前目录生成 XLSX 或 PNG 文件。
