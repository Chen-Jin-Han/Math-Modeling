# 40 个最常用模型整理的研赛论文

本资料库按 40 类方法整理了 1069 篇研究生数学建模竞赛论文，是当前三个模型案例库中规模最大、覆盖面最广的一组。每类模型对应独立目录，适合检索复杂工程系统、多源数据和多阶段优化案例。

## 模型体系

| 类别 | 代表方法 |
| --- | --- |
| 评价与决策 | AHP、TOPSIS、DEA、投影寻踪、秩和比、模糊综合评价 |
| 回归与统计 | 回归、逐步回归、逻辑回归、典型相关、相关系数、方差分析、PCA、因子分析 |
| 时间序列与预测 | ARMA、时间序列分解、VAR、灰色预测、灰色关联、小波分析、马尔科夫 |
| 优化与智能算法 | 规划、动态规划、遗传算法、粒子群、蚁群、模拟退火、蒙特卡洛 |
| 机器学习与仿真 | 聚类、决策树、神经网络、支持向量机、元胞自动机 |
| 机理与图网络 | 微分方程、排队论、博弈论、Dijkstra、Floyd、插值与拟合 |

## 学习重点

- 如何把工程背景转化为决策变量、状态变量、目标函数和约束。
- 如何组合多个子模型并处理不同阶段之间的数据传递。
- 如何为复杂算法设置基线、消融实验、误差指标和敏感性分析。
- 如何在篇幅限制内组织模型流程图、结果图表与可执行建议。

## 检索建议

先按模型目录筛选，再使用 PDF 全文搜索查找具体应用关键词。对于同一问题，优先比较不同方法的假设、计算成本、可解释性和稳健性，不以算法复杂度代替模型质量。
