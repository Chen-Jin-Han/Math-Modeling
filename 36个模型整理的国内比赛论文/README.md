# 36 个模型整理的国内比赛论文

本资料库按 36 类常用模型整理了 312 篇国内数学建模竞赛论文。所有论文均按模型目录归类，可用于快速查找中文建模表达、指标设计和算法应用案例。

## 模型体系

- 综合评价：层次分析、TOPSIS、模糊综合评价、投影寻踪、主成分分析、因子分析。
- 回归与统计：多元回归、逐步回归、逻辑回归、方差分析、相关系数、典型相关分析、拟合模型。
- 预测分析：灰色预测、灰色关联、ARMA、马尔科夫模型、小波分析。
- 机器学习：聚类、决策树、支持向量机、神经网络。
- 优化算法：线性规划、动态规划、遗传算法、粒子群、蚁群、模拟退火、蒙特卡洛。
- 机理与网络：微分方程、元胞自动机、排队论、博弈论、Dijkstra、Floyd、插值。

## 推荐使用方法

1. 先从题目中的决策目标、数据规模和约束类型确定模型候选。
2. 阅读同一目录中的多篇论文，比较模型变体和评价指标。
3. 将值得借鉴的建模步骤整理为自己的方法笔记。
4. 复现时重新估计参数并设置对照模型，不能照搬案例结论。
