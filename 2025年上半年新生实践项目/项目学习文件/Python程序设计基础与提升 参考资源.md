# 典型的库

## 数值计算 numpy

包含了大量的科学计算库及对应的函数，如矩阵计算，曲线拟合，解线性方程组，解非线性方程组。

有大量的基础函数与MATLAB的函数同名。



## 数据操作库 Pandas

读取csv,xls,xlsx文件等文件。

有大量的数据操作，如统计等，甚至具备类似SQL（数据库结构化查询语言）的一些操作功能，进行分组、过滤等等。
