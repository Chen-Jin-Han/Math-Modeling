



# 开发环境搭建

## 前提：以Pyhcarm为集成开发环境



## 推荐方式1：编译环境用基本Python

这种方式：先安装Python 3.X；

建议安装到D盘目录：如目录D:\Python38



切换到 D:\Python38\Scripts目录下执行pip命令进行安装。

然后用下列命令安装库：

pip install  库名  -i   https://pypi.tuna.tsinghua.edu.cn/simple/    



## 推荐方式2：编译环境用Anconda



先安装Anconda，（好处：已经包含了大量的第3方库，不用安装）

再安装Pycharm，然后配置Pycharm的编译环境指向Anconda下的Python可执行文件。

可以再在Anconda的命令行里面安装或更新其他第三方库。
