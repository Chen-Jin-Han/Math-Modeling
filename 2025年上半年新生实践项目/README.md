# 2025年上半年新生实践项目

项目主题为“高速公路出口设计优化”。研究通过离散时间交通仿真，对双侧合并与单侧合并两种出口方案进行比较，并以车辆吞吐量、平均通行时间等指标评价和优化出口设计。

## 目录结构

- `项目主题/`：项目指导手册及高速公路仿真、变道超车任务讲稿。
- `项目结题论文/`：最终报告 `终稿.pdf`。
- `项目结题可运行代码/`：MATLAB 仿真与优化脚本，以及原始“项目结果”代码归档。
- `项目补充材料/`：过程版报告、答辩 PPT、MATLAB 图形与自动保存文件。
- `项目学习文件/`：Python、PyQt5、深度学习和变道模型等学习材料。

## 模型与方法

- 泊松到达与指数分布车流生成
- 车辆加速、减速、排队和变道行为模拟
- 单侧/双侧合并方案对比
- 吞吐量、平均通行时间等性能指标
- 模拟退火、遗传算法等参数优化尝试

## 运行说明

代码使用 MATLAB。建议从 `项目结题可运行代码/runSingleSim.m` 开始阅读和运行；部分脚本使用 `simulannealbnd`，需要 Global Optimization Toolbox。其他 `untitled*.m` 和 `项目结果/` 中保留了不同阶段的实验版本，文件名和入口尚未统一，运行前应先查看脚本顶部的参数与外部数据要求。

```matlab
cd('项目结题可运行代码')
run('runSingleSim.m')
```
