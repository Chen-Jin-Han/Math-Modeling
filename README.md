## 竞赛项目目录约定

```text
项目名称/
├─ 题目及相关附件/
├─ 论文/
├─ 论文补充材料和附件/
└─ README.md
```

- `题目及相关附件`：赛题、原始数据、官方政策和论文模板。
- `论文`：最终 PDF 及可编辑源文件。
- `论文补充材料和附件`：代码、输出表格、图像、AI 使用说明和提交材料。
- 某类材料缺失时仍保留空目录，使不同项目保持统一结构。

新生实践项目和课程报告采用与内容相匹配的专用结构，具体说明见各自 README。

## 推荐使用路径

### 复盘一道竞赛题

1. 独立阅读题目并完成问题拆解。
2. 根据目标、数据和约束选择候选模型。
3. 在模型论文库中检索方法案例，比较适用条件。
4. 阅读往届优秀论文，重点分析假设、指标、验证和敏感性分析。
5. 回到个人项目代码复现实验并记录差异。

### 按模型查找案例

- 评价决策：AHP、TOPSIS、PCA、因子分析、模糊综合评价、DEA。
- 预测统计：回归、时间序列、灰色预测、方差分析、相关分析。
- 优化计算：规划、遗传算法、粒子群、模拟退火、蚁群、动态规划。
- 机器学习：聚类、决策树、SVM、神经网络、集成方法。
- 机理仿真：微分方程、元胞自动机、排队论、蒙特卡洛、图论。

## 维护约定

- 新竞赛项目优先沿用三目录结构并补充项目 README。
- 论文尽量同时保留最终 PDF 与源文件；过程版本归入补充材料。
- 可运行代码应记录语言、依赖、入口、数据要求与验证状态。
- 保留官方赛题编号、论文编号和原始文件名，以便追溯来源。
- 资料库规模较大；纳入 Git 时建议使用 Git LFS 或适合大文件的存储方案。
