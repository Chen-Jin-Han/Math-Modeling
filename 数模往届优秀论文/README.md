# 数模往届优秀论文

本资料库汇总全国大学生数学建模竞赛与 MCM/ICM 的历年赛题、优秀论文和题目数据附件。当前共有约 4691 个文件，其中包括 1058 份 PDF，以及 Word、Excel、CSV、图片和视频等配套材料。

## 目录结构

```text

├─ 1992-2018国赛优秀论文/
├─ 2019国赛优秀论文/ … 2024数模国赛优秀论文/
└─ 国赛赛题/
   └─ 2015赛题/ … 2024赛题/

美赛/数学建模美赛/
├─ 美赛赛题/
│  └─ 2017/ … 2024/
└─ 美赛特等奖论文/
   ├─ 1989-2020美赛建模论文/
   ├─ 2021、2022、2023 年优秀论文资料
   └─ 无水印：美赛2024年特等奖论文/A/ … F/
```

## 收录内容

- 国赛：1992—2024 年优秀论文资料，以及 2015—2024 年赛题与附件。
- 美赛：2017—2024 年 A–F 题及数据，1989—2024 年优秀/O 奖论文资料。
- 2021 年美赛 C 题：赛题、数据表、背景资料及按 GlobalID 关联的现场图片附件。
- 2024 年美赛：A–F 各题优秀论文；A 题目录含多份可直接阅读的编号论文。

## 推荐复盘流程

1. 进入对应赛事和年份目录，先阅读题目与数据说明。
2. 不参考论文完成自己的问题拆解、假设和候选模型设计。
3. 按题号阅读优秀论文，对比指标、算法、图表与验证方案。
4. 记录值得借鉴的结构和方法，同时分析论文局限。
5. 引用具体观点、图表或数据时回溯原论文并注明作者与来源。

## 检索建议

可使用系统搜索按年份、题号、论文编号或模型关键词定位文件。例如搜索 `2024`、`Problem C`、`灰色预测`、`Monte Carlo`。部分老文件使用 DOC、XLS 或 CAJ 格式，需要相应阅读软件。
