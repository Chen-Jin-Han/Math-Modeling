# 20 个最常用模型整理的美赛论文

本资料库按 20 种常见数学模型整理了 201 篇 MCM/ICM 论文。每种模型拥有独立目录，目录内均为可直接阅读的 PDF，适合模型选型、英文术语学习和论文结构复盘。

## 模型目录

| 类别 | 模型 |
| --- | --- |
| 综合评价与降维 | 层次分析法 AHP、优劣解距离法 TOPSIS、主成分分析 PCA、因子分析 |
| 统计分析与预测 | 回归分析、逻辑回归、方差分析、时间序列 ARMA、灰色预测 |
| 机器学习 | 聚类分析、决策树、神经网络、支持向量机 |
| 优化与系统仿真 | 动态规划、模拟退火、排队论、元胞自动机 |
| 图论与数值计算 | Dijkstra、Floyd、插值算法 |

## 使用方式

1. 根据问题目标选择类别：评价、预测、分类、优化或仿真。
2. 在对应模型目录中横向比较多篇论文，不以单篇案例作为固定模板。
3. 重点记录变量定义、目标函数、约束、参数估计、检验和敏感性分析。
4. 对英文论文可建立术语表，学习摘要、图题、表题和结论的规范表达。

## 注意事项

模型名称相同不代表假设与数据条件相同。使用前应检查题目是否满足模型前提，并设置基线方法、误差指标和稳健性检验。论文资料版权归原作者及赛事组织方所有。
