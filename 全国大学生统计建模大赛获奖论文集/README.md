# 全国大学生统计建模大赛获奖论文集

本目录收录 140 余份全国大学生统计建模大赛获奖论文及一张来源说明图片。主题覆盖数字经济、公共卫生、教育、消费行为、环境治理、金融风险、文本挖掘、空间统计和机器学习等方向。

## 常见方法

- 问卷调查、信效度分析、Logistic 回归与结构方程模型
- 面板数据、投入产出、DEA、GMM 与空间计量
- 时间序列、Prophet、ARIMA 和函数型数据分析
- 文本挖掘、LDA、情感分析与虚假评论识别
- SVM、XGBoost、LightGBM、神经网络与集成学习
- 地理加权回归、贝叶斯时空模型和多源数据融合

## 使用方式

文件名通常包含论文题目与作者，可直接使用系统搜索按关键词查找，例如“数字经济”“碳排放”“文本挖掘”或具体模型名称。部分文件带 `_2` 后缀，是归档中保留的重复副本；未擅自删除，以免在未经逐页比对时误删不同版本。

这些论文适合用于学习统计研究设计、指标构建、实证分析和结果解释。不得将其作为课程或竞赛作品直接提交；引用时应注明作者与论文来源。
